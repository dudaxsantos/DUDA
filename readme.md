Documentação de Projeto: Especificação Inicial do Sistema
1. Nome da Squad
DataFlow Squad
2. Escopo do Sistema
O sistema tem como objetivo automatizar o processamento de dados comerciais, realizando o consumo de dados brutos de vendas, a validação rigorosa de integridade e a exibição clara e estruturada dos resultados processados para tomada de decisão.
3. Requisitos Funcionais (RF)
O sistema deve permitir que o usuário faça o upload de arquivos contendo dados brutos de vendas no formato CSV.
O sistema deve validar a integridade estrutural e os campos obrigatórios dos dados inseridos, identificando registros corrompidos ou inconsistentes.
O sistema deve exibir os resultados consolidados do processamento e validação em um painel visual (dashboard) interativo.
4. Requisitos Não-Funcionais (RNF)
O sistema deve validar a qualidade e integridade de um arquivo de vendas de até 100 MB em menos de 3 segundos.
O sistema deve garantir a segurança dos dados trafegados e armazenados por meio de criptografia padrão de mercado (como AES-256 e HTTPS).
